# Nexxus

Sistema web de **emissão de NFS-e** (Nota Fiscal de Serviço Eletrônica) no padrão nacional brasileiro (Sistema Nacional NFS-e / SPED).

## O que é

O Nexxus é uma plataforma que permite emitir, validar e gerenciar notas fiscais de serviço eletrônico de forma integrada e automatizada. Foi desenvolvido para facilitar a rotina de emissão fiscal de instituições, unificando em um só lugar o cadastro de serviços, a emissão de DPS, a validação contra o padrão oficial e o controle financeiro.

## Principais funcionalidades

- Emissão de DPS/NFS-e no padrão nacional
- Cadastro mestre de serviços com códigos de tributação
- Validação contra o esquema (XSD) oficial
- Assinatura digital com certificado A1/A3
- Envio para o ambiente de homologação e produção do Sefin Nacional
- Cancelamento de notas emitidas
- Gestão de tomadores, projetos e relatórios financeiros

## Tecnologias

- ASP.NET Core (C#)
- Banco de dados SQLite
- Interface web responsiva
